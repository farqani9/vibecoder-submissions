# vibecoder submissions

This repository collects suggestions and corrections for **vibecoder**, a hand-checked directory of agent skills (GitHub repos with SKILL.md files) for vibe coders and agentic engineers.

## Suggest a skill

Use the **Submit** page on the vibecoder site. Paste the skill's GitHub link and the page:

- fills in the name, stars and description from GitHub
- checks that the repo contains a SKILL.md, isn't archived, and isn't already listed
- opens a prefilled issue here

You can also open the [Submit a skill](../../issues/new?template=submit-skill.yml) form directly.

Every suggestion is reviewed by hand before it's listed. A skill is listed when:

- the repo contains at least one SKILL.md
- it's maintained: not archived, and not marked deprecated in its README
- it's a skill, not an "awesome" list of links

Nothing listed is paid for.

## Report a problem with a listing

Spotted a wrong star count, a dead repo, or your own project listed and you'd like it changed or removed? [Open an issue](../../issues/new) and link the entry.
